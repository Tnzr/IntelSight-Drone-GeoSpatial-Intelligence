# Engineering

This directory contains the technical architecture, phase plan, and engineering requirements for IntelSight.

## Contents

- `engineering-requirements.md` — system requirements and integration goals
- `implementation-plan.md` — project delivery roadmap and milestones
- `px4-multicamera-platform.md` — multi-lateral perception architecture and hardware recommendation
- `sigint-payload-roadmap.md` — roadmap for Wi-Fi, Bluetooth, and RF sensing payloads
- `technical-architecture.md` — system view of telemetry, perception, geospatial, and AI layers

## Objective

The purpose of this directory is to maintain a disciplined engineering progression: offline intelligence first, then autonomous PX4 capability, and then fleet/SIGINT expansion.
